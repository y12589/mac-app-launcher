Mac App Launcher
======================

## 1.30.0 升级说明

本版本将首页调整为「顶部常用应用 + 算力福利卡册主体」，移除应用笔记、关联知识、反向链接和应用资料 Bases 入口。不会删除用户已创建的笔记文件，也不清空旧 `notePath` 字段。此次不新增或删除持久化字段，不改变 `schemaVersion` 与领取记录结构。

适用：macOS + Obsidian 桌面版（Intel / Apple Silicon）。
当前版本：1.30.0（作者：阎大大）。完整更新记录见 CHANGELOG.md。

插件定位：在 Obsidian 内统一管理 macOS 本地应用、网页入口与算力福利；首页上方快速启动常用软件，下方直接管理福利卡册。

完整使用说明（每个功能的详细用法）：[USER-GUIDE.md](USER-GUIDE.md)。

## 1.30.0 首页结构

- 顶部时钟、日期与搜索。
- 顶部常用应用：最多 8 个置顶/高频应用，支持启动、搜索、右键和置顶拖拽。
- 首页主体直接展示算力福利卡册：统计、全年活跃热力图、卡片收藏、分类和领取操作。
- 应用管理仍保留在右上角菜单中，用于扫描、分类、客户端/网页入口和资料维护。
- 原有 `workspaceOrder`、`homeLayout` 等旧布局配置保留，但不再控制首页渲染。

本版本移除应用笔记、关联知识、反向链接和应用资料 Bases 入口；不会删除 Vault 中既有笔记，也不会清空旧 `notePath`。Markdown `app-launcher` 代码块、每日笔记启动日志和场景文件步骤仍保留。

## 应用管理基础（1.7.x）

1. 扫描本机应用、原生图标、分类导航、置顶、拖拽排序、一键启动。
2. 分类可自定义：新增、重命名、删除、排序，每个分类可配 emoji 图标。
3. 批量分类与归类学习：手动改过的分类按应用名记住，之后扫描自动命中。
4. 拼音搜索：首字母（wx）或全拼（weixin）匹配中文应用名；快速启动面板（Cmd+Shift+Space）与搜索框均生效。
5. 单应用快捷键、应用详情弹窗（介绍、用途、快捷键可编辑）。
6. 场景模式：一键启动/关闭一组应用；场景启动 0.5 秒错峰；关闭按 bundle ID 匹配；可设置打开 Obsidian 约 3 秒后自动拉起指定场景。
7. 设置页自动更新（失败自动重试、支持下载加速镜像）、服务状态行、关于页内置更新日志。

## 与 Obsidian 深度融合（1.8 – 1.9）

8. Markdown 启动卡片：笔记里写 ` ```app-launcher ` 代码块（`app: 应用名`，可多个、可 `note:` 自定义说明），渲染成带图标和打开按钮的卡片。
9. 文件右键菜单：按文件类型推荐应用打开；文件 frontmatter 可声明 `app-scene`，右键启动对应场景；文件夹可在 Finder 中打开。

## 其他 Obsidian 工作流（1.11 – 1.13）

10. 每日笔记启动日志：设置页开启后，每次启动应用自动在当天日记「应用使用记录」小节追加一行；尊重 Daily Notes 插件的目录与文件名格式。默认关闭。
11. 启动参数白名单：编辑器类应用（VS Code、Cursor 等）右键可「打开当前库」，终端类应用（Terminal、iTerm 等）右键可「进入当前笔记目录」。只允许传递目录路径。
12. 公开 API：`window.MacAppLauncher.launch(name)` / `launchScene(name)` / `apps()`，供 QuickAdd 宏、Templater 脚本与其他插件直接调用。
13. 配置导入导出：设置页一键导出应用、场景、分类与归类规则为 JSON，粘贴到其他 Vault 导入即可复刻整套工作环境。

## Canvas 工作流（1.15 – 1.17）

14. 场景导出画布：场景管理行点「画布」，生成 `工作流/场景名.canvas`——每个应用一个可点击启动的节点，按执行顺序连线串联。
15. 画布自动执行：命令面板「执行当前画布的工作流」，按连线拓扑顺序启动应用（已运行的跳过）、打开 file 节点指向的笔记；检测到循环连线自动拦截；结束后汇总启动/打开/跳过数量并点名失败项。设置页有开关（默认开）。
16. 场景运行状态感知：启动场景时已在运行的应用自动跳过，不重复拉起。

## 统一应用资源与算力卡册（1.27–1.28）

- 应用资源支持本地客户端和纯网页应用；可在应用管理中添加网页应用，也可给本地应用配置官方网站
- 首页启动采用 Smart 策略：优先启动本地客户端，客户端不可用时回退到官方网站
- 福利卡片通过稳定 `appId` 关联统一应用资源；一个应用可以关联多张福利卡片，不重复维护应用名称、图标和客户端入口
- 福利卡片可配置专属领取网页；留空时使用关联应用的官方网站
- 支持客户端 / 网页双向选择；打开入口不自动打卡，用户完成实际领取后手动确认
- 支持一次性、每日、每月领取周期，按周期防止重复确认，并可撤销当前周期记录
- 领取记录保存确认时估值快照；后续修改卡片估值不会改写历史累计价值
- 支持福利生效日期、截止日期和停用状态；过期或停用卡片保留在卡册中，但不计入当前可领取价值
- 卡片详情展示最近领取历史；配置导入导出包含卡片和领取记录

升级：
推荐用设置页自动更新：打开插件设置 → 检查更新 → 按提示更新，data.json 与 icons 文件夹不受影响。
手动覆盖（备用）：
1. 完全退出 Obsidian（Cmd+Q）。
2. 解压 ZIP。
3. 用 mac-app-launcher 文件夹覆盖当前库的 .obsidian/plugins/mac-app-launcher/
4. 保留旧目录中的 data.json（不要删除），icons 文件夹也可保留。
5. 重新打开 Obsidian。

Agent API（HTTP，供本机 Agent 调用）：
- Base URL: http://127.0.0.1:43171（端口冲突时自动换，以设置页「服务状态」为准）
- 除健康检查外需请求头 `Authorization: Bearer <TOKEN>`（管理页可查看/重置）

1) 检查服务：
curl http://127.0.0.1:43171/v1/health

2) 查询已勾选应用（支持 ?category= 与 ?q= 拼音搜索，返回含使用统计）：
curl -H "Authorization: Bearer <TOKEN>" "http://127.0.0.1:43171/v1/apps?q=微信"

3) 查询分类：
curl -H "Authorization: Bearer <TOKEN>" http://127.0.0.1:43171/v1/categories

4) 启动应用（精确无果自动模糊匹配，候选不唯一返回 409）：
curl -X POST http://127.0.0.1:43171/v1/launch \
  -H "Authorization: Bearer <TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{"app":"ChatGPT"}'

5) 批量启动（上限 20 个）：
curl -X POST http://127.0.0.1:43171/v1/launch-batch \
  -H "Authorization: Bearer <TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{"names":["微信","飞书"]}'

插件内公开 API（供 QuickAdd / Templater / 其他插件）：
```js
await MacAppLauncher.launch("VS Code");      // 模糊启动应用
await MacAppLauncher.launchScene("写作模式"); // 启动场景
MacAppLauncher.apps();                        // 列出已勾选应用
```

Agent 推荐指令：
“当我要求打开某个 Mac 客户端时，先调用 Mac App Launcher 的 GET /v1/apps 查询允许启动的软件；如果用户指定的软件在列表中，调用 POST /v1/launch，传入精确 app 名称或 id。不要自行使用 open 命令或猜测应用路径。如果应用不在列表中，告诉我先在 Obsidian 插件里勾选该应用。”

安全：
- Agent API 仅绑定 127.0.0.1，随机 Bearer Token（SHA-256 哈希存储），限速每来源每分钟 120 次。
- 只能启动插件中已勾选的应用，不接受任意路径或 shell 命令。
- 启动参数白名单仅允许传递目录路径给编辑器/终端类应用。
- 退出 Obsidian 后 API 随插件停止。

应用中心：
- 首页顶部：常用应用快捷栏，最多展示 8 个置顶/高频应用。
- 首页主体：算力福利卡册，包含统计、全年活跃、福利卡片、周期筛选和人工确认领取。
- 点击应用：启动客户端；应用右键保留 Finder、路径复制、置顶、编辑等操作，不再提供应用笔记入口。
- 置顶与拖拽排序仍由应用管理维护；首页只显示最多 8 个常用应用，不再展示完整分类客户端网格。
- 快速启动面板（Cmd+Shift+Space）：搜应用、搜场景，回车启动。

## 历史首页布局（1.26，1.30.0 起不再用于首页渲染）

- 旧版首页曾支持大时钟、应用磁贴多尺寸、自由布局和分类模块拖拽。
- 相关 `homeLayout`、`workspaceOrder` 等配置继续保留在 `data.json` 中，不执行删除或重置；1.30.0 首页改为常用应用快捷栏 + 算力福利卡册。
