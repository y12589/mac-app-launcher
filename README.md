# Mac App Launcher

A macOS-only Obsidian plugin for discovering, organizing, and launching installed apps.

## Features

- Scan common macOS application folders.
- Choose which apps appear in the launcher.
- Drag to reorder and organize apps by category.
- Keep pinned apps at the top without moving them into a separate category.
- View and edit descriptions and use cases for each app.
- Launch apps directly from Obsidian.
- Localhost Agent API for local agents to query and launch enabled apps.

## Development status

The initial source import and first GitHub Release are still being prepared. Do not install this repository through BRAT until a complete release containing main.js, manifest.json, and styles.css is published.
